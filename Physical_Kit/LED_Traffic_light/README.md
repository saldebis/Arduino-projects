# 🚦 Arduino Traffic Light

A simple Arduino project that simulates a **traffic light system using three LEDs**: red, yellow, and green.

The project demonstrates basic **digital output control, timing, and sequential LED operation** using an Arduino.

## 🛠️ Components

* Arduino board
* 🔴 Red LED
* 🟡 Yellow LED
* 🟢 Green LED
* 3 × Resistors
* Breadboard
* Jumper wires

## ⚙️ How It Works

The Arduino controls the three LEDs through digital output pins.

The LEDs turn on sequentially to simulate a traffic light:

```text
🔴 Red    → Stop
🟡 Yellow → Prepare / Caution
🟢 Green  → Go
```

After the green light, the sequence repeats continuously.
