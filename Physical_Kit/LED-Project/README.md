# 💡 LED Control with Arduino

A basic Arduino project demonstrating how to control an LED using digital output.

This project was created as part of my hands-on practice with **Arduino programming, digital electronics, and microcontroller I/O**.

## 🛠️ Components

* Arduino board
* LED
* Resistor
* Breadboard
* Jumper wires

## 💻 Technologies

* Arduino
* C/C++
* Digital I/O

## ⚙️ How It Works

The Arduino sets a digital pin as an output and controls the LED by switching the pin between `HIGH` and `LOW`.

```cpp
digitalWrite(LED_PIN, HIGH);
delay(1000);

digitalWrite(LED_PIN, LOW);
delay(1000);
```

The LED turns **ON for one second** and **OFF for one second**, creating a continuous blinking pattern.
